First public release. Theseus is a native Mac app for Claude Code: it runs the `claude` CLI you already have, one process per conversation, and draws the conversation in AppKit.

- Each conversation is a window, and windows group as tabs. The whole transcript is one text view, so a selection can run from the first prompt to the last reply and Find searches all of it.
- When Claude asks for permission, asks a question or proposes a plan, you answer on a card inside the transcript. The status row under the prompt switches the model and permission mode and shows how full the context is.
- Window > Projects (⇧⌘0) lists every Claude Code session on your Mac. A session waiting on you has Allow and Deny right in its row.
- New tabs open on a start page of the project's recent sessions. In the sidebar, subsessions sit under the session that started them, and View > Sidebar Configuration picks what each row shows.
- Code blocks are highlighted and have Copy; shell blocks also have Run, which opens the command in Terminal.
- If a session is already running in the Claude desktop app or a terminal, Theseus follows it read-only instead of starting a second process.

You need macOS 26 and a logged-in Claude Code install. This version uses ClaudeEngine 0.1.0 and was tested against Claude Code 2.1.327. Pin, rename and archive in the Projects window have no undo yet.
